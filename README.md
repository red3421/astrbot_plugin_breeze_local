
# Breeze 本地语音（AstrBot 插件）

把本机跑的 [Breeze-TTS-2.cpp](https://github.com/HoppouAI/Breeze-TTS-2.cpp) 服务接进 AstrBot。
不自带模型，纯客户端：**拉服务端的音色库，用你存好的声音说话**。

## 它能干什么

- `/tts <文字>` — 读出来；引用一条消息再发 `/tts` 也能读那条
- `/tts_voice list` / `show` — 列音色库、看当前状态
- `/tts_cache stats` / `clear` — 看缓存占用、清缓存
- **LLM 工具 `breeze_speak`** — 模型觉得该发语音时自己调，可带表演指令
- **主动转语音** — 按概率把 bot 的文字回复换成语音，可只发语音不发字
- **插件页「语音库」** — 拉取音色列表、点选默认音色、看缓存、清缓存

## 安装

1. 整个 `astrbot_plugin_breeze_local` 文件夹丢进：

   ```
   AstrBot/data/plugins/astrbot_plugin_breeze_local/
   ```

2. AstrBot WebUI → 插件页 → 重载插件
3. 打开插件配置，填 **服务地址**

## 配置

### 基础

| 配置项 | 默认 | 说明 |
|---|---|---|
| `api_base` | `http://127.0.0.1:8080` | breeze-server 地址。不同机器填局域网 IP，如 `http://192.168.5.7:8080` |
| `voice_id` | 空 | 默认音色 id，留空用音色库第一个 |
| `cfg_scale` | `2.0` | 表现力强度。`1.0` 原样朗读，2~3 语气更足，超 3 刺耳 |
| `seed` | `42` | 随机种子，换个数字换个说法 |
| `timeout` | `120` | 请求超时秒数 |

### 调用配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `auto_voice_enabled` | `false` | 总开关，打开才会主动转语音 |
| `only_llm_result` | `true` | 只处理 LLM 返回的消息，不碰指令回执 |
| `auto_voice_probability` | `0.15` | 主动转语音概率，0~1 |
| `max_text_length` | `50` | 超过这个长度不转语音，0 不限 |
| `replace_text` | `false` | **拦截文字，只发语音**。打开后转语音成功时不再发原文字 |

### LLM 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `emotion_enabled` | `true` | 用 LLM 判断情绪，生成表演指令再交给 Breeze |
| `emotion_provider_id` | 空 | 判断情感用的提供商，留空用当前默认。建议挑便宜快的小模型 |

### 缓存配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `cache_enabled` | `true` | 参数完全一致时复用本地缓存音频 |
| `cache_expire_hours` | `30` | 过期小时数，`0` 表示永不过期 |

缓存 key = 音色 + 文本 + 表演指令 + cfg + 种子。任意一项变了就重新推理。

## 服务端要求

AstrBot 和 TTS **不在同一台机器**时，服务端必须监听所有网卡：

```powershell
breeze-server.exe "模型.gguf" --host 0.0.0.0 --port 8080 --webui
```

防火墙记得放行 8080。

## 音色从哪来

音色是你自己在服务端存的，不是插件带的。

**用 WebUI（推荐）** — 打开 `http://<服务端IP>:8080/`，切到「语音库」页签，上传一段干净录音 + 一字不差的文字稿，存个名字。

**用命令行**

```powershell
breeze-cli.exe 模型.gguf --ref-audio 参考.wav --ref-text "参考音频的准确文字" --save-voice laotai
```

存完插件页点「刷新」就能看到。

> 参考音频 5~15 秒最合适，要干净、无背景音乐。转写必须和音频**一字不差**，错一个字克隆质量就崩。

## 主动转语音怎么工作

流程挂在 `on_decorating_result` 上，LLM 回复生成完之后、发出去之前动手：

1. 检查总开关、是否 LLM 结果、有没有已经带语音
2. 清洗文本（去 markdown、链接、代码块）
3. 检查长度限制
4. 掷骰子，概率不中就直接放过
5. 判断情感 → 拿到表演指令
6. 合成语音，塞进消息链

**拦截文字** 打开时，消息链直接换成只有语音；关闭时是语音在前、文字在后。

任何一步失败都会**保留原文字**，不会让消息消失。

## 故障排查

| 现象 | 处理 |
|---|---|
| 拉取音色库失败 → 连不上 | 服务端没开，或 `api_base` 填错，或服务端没加 `--host 0.0.0.0` |
| 音色库是空的 | 服务端还没存音色，去 WebUI 语音库存一个 |
| 合成失败 HTTP 409 | 服务端一次只能跑一个请求，等上一条出完 |
| 发出去是杂音 | 一般是音频头问题，本插件已把裸 PCM 包成 WAV，若仍异常请反馈 |
| 模型不调用语音工具 | 在人格提示词里写明「需要语音时调用 `breeze_speak`」 |
| 主动转语音不生效 | 确认 `auto_voice_enabled` 打开、概率不为 0、文本没超长 |


## 许可

插件代码随你处置。Breeze TTS 2 的**模型权重是 BreezeBlue 研究与非商用许可**，自托管产出的音频不能直接商用。
